# پورتفولیوی فاطمه شیری

سایت شخصی دوزبانه (فارسی پیش‌فرض، انگلیسی). React، TypeScript، Vite و Tailwind CSS. بدون بک‌اند و بدون سرویس پولی.
دلیل‌های طراحی در [DESIGN.md](DESIGN.md) آمده است.

## اجرا روی کامپیوتر خودتان

پیش‌نیاز: Node.js نسخه‌ی ۲۲ یا بالاتر.

```bash
npm install
npm run dev
```

بعد `http://localhost:5173` را باز کنید. هر تغییری در فایل‌ها فوراً در مرورگر دیده می‌شود.

نسخه‌ی نهایی را این‌طور بسازید و ببینید:

```bash
npm run build
npm run preview
```

و بعد `http://localhost:4173`.

## نسخه‌ی تک‌فایلی برای مرور

```bash
npm run build:standalone
```

خروجی `preview/fatemeh-shiri-portfolio.html` است: یک فایل حدوداً ۷۰۰ کیلوبایتی با همه‌ی فونت‌ها و کدها. بدون اینترنت و فقط با دوبار کلیک باز می‌شود.

## ویرایش محتوا

| چه چیزی | کجا |
|---|---|
| متن فارسی | `src/i18n/fa.ts` |
| متن انگلیسی | `src/i18n/en.ts` |
| ایمیل و لینکدین | `src/data/profile.ts` |
| متا تگ‌ها و تصویر اشتراک‌گذاری | `index.html` و `static/og-image.png` |
| رنگ‌ها، فونت‌ها و فاصله‌ها | `src/styles/index.css` (بخش Design tokens) |

بعد از ویرایش متن‌ها این را اجرا کنید:

```bash
npm run check
```

این دستور خطاهای تایپ‌اسکریپت را می‌گیرد، و در متن فارسی «ي/ك» عربی، جای خالی نیم‌فاصله و رقم لاتین را پیدا می‌کند. در متن انگلیسی هم هر حرف فارسی را گزارش می‌کند. `npm run build` همین بررسی را خودکار انجام می‌دهد.

## انتشار در GitHub Pages

سایت در `https://shirif90-a11y.github.io` منتشر می‌شود و کدش در مخزن `shirif90-a11y/shirif90-a11y.github.io` است.

فایل `.github/workflows/pages.yml` با هر push به شاخه‌ی `main` سایت را می‌سازد و منتشر می‌کند. برای به‌روزرسانی سایت کافی است تغییرها را کامیت و push کنید:

```bash
git add .
```

```bash
git commit -m "Update content"
```

```bash
git push
```

پیشرفت ساخت در زبانه‌ی **Actions** مخزن دیده می‌شود و معمولاً یکی دو دقیقه طول می‌کشد. نشانی کامل سایت (`SITE_URL`) در GitHub خودکار پر می‌شود.

## انتشار در GitLab Pages (جایگزین)

فایل `.gitlab-ci.yml` هم آماده است. اگر روزی بخواهید سایت را در GitLab منتشر کنید، یک پروژه بسازید، کد را به شاخه‌ی اصلی‌اش push کنید و job به اسم `pages` را در **Build → Pipelines** دنبال کنید. نشانی در **Deploy → Pages** نوشته می‌شود.

### تنظیم مسیر و نشانی

- **`BASE_PATH`:** پیش‌فرض `./` است. یعنی همه‌ی مسیرها نسبی‌اند، و همان خروجی هم زیر مسیر پروژه کار می‌کند، هم روی دامنه‌ی اصلی، هم روی دامنه‌ی اختصاصی. فقط اگر مسیر مطلق می‌خواهید آن را عوض کنید؛ مثلاً `BASE_PATH=/portfolio/ npm run build`.
- **`SITE_URL`:** نشانی کامل سایت. فقط برای canonical، hreflang و تصویر اشتراک‌گذاری لازم است. در GitHub و GitLab خودکار پر می‌شود.

## ساختار

```text
src/
  i18n/          متن هر دو زبان، با یک نوع مشترک (types.ts)
  components/    بخش‌های صفحه
  hooks/         بخش فعال در ناوبری، ظاهر شدن هنگام اسکرول
  styles/        توکن‌ها، فونت‌ها و استایل اجزا
  assets/fonts/  سه فونت آزاد (OFL)، فقط زیرمجموعه‌های لازم
scripts/         بررسی متن، پیش‌رندر فارسی، نسخه‌ی تک‌فایلی
static/          favicon، تصویر اشتراک‌گذاری، robots.txt
```

صفحه هنگام ساخت به فارسی پیش‌رندر می‌شود. یعنی متن، پیش از اجرای جاوااسکریپت، در HTML هست و بدون جاوااسکریپت هم خوانده می‌شود.
